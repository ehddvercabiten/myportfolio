# Developer Portfolio

A static, responsive React + TypeScript portfolio.

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Personalize

Most content is centralized in:

`src/data.ts`

Update:
- name
- email
- GitHub
- LinkedIn
- resume path
- skills
- projects
- experience

Place your resume at:

`public/resume.pdf`

## Deploy

The generated `dist` folder can be deployed to Cloudflare Pages or any static hosting provider.
